# Viezo theme

Custom WordPress theme for [viezo.lt](https://viezo.lt). It uses Tailwind CSS 3 + SCSS, vanilla JS, ACF Pro flexible content blocks and Polylang, and it's built with Vite.

## Requirements

- WordPress 6.5+ and PHP 7.4+
- Plugins: **Advanced Custom Fields Pro** (required), Polylang Pro, Yoast SEO, WPForms / Contact Form 7
- Node 22 (see `.nvmrc`), only needed for building assets

## Custom content types

These are defined in ACF (see [acf.md](acf.md)), not in PHP:

- **Case studies** (`case-study`): archive at `/case-studies/`, templates `archive-case-study.php`, `single-case-study.php`
- **Case study type** (`case-study-type`) taxonomy: `taxonomy-case-study-type.php`
- **Partners** (`partner`): rendered by the `partners` block

Global settings live on the ACF options page **Settings → Viezo Settings** (registered in `inc/extras.php`).

## Analytics

- **Google Analytics 4** is loaded by `inc/analytics.php` (gtag.js, early in `<head>`). The Measurement ID is set in **Settings → Viezo Settings → Analytics**; empty = the theme default `G-3NFFVXWCVK`, `off` disables it.
- **Consent Mode v2:** analytics cookies are only used after the visitor clicks OK on the cookie banner (GlowCookies, `localStorage.GlowCookies = "1"`). Before that GA4 gets cookieless pings only, so those visits don't show up in Realtime. Ads storage is always denied.
- **Microsoft Clarity** is loaded separately (not by the theme).
- The pricing setup builder's funnel events go to GA4, Clarity and the site's own log (see [templates-and-blocks.md](templates-and-blocks.md#pricing-setup-builder)).
