# AI buyer prompts

The fixed set of questions we ask ChatGPT, Perplexity, Gemini and Copilot every month (see `05-tracking/ai-visibility/`). Keep wording stable so months compare; add new prompts at the end with a new ID, never reword old ones.

Intent: **D** discovery (which vendors), **E** education (how/what), **C** comparison, **L** local/regional.
