# Viezo WordPress theme

Theme for [viezo.com](https://viezo.com): Tailwind + SCSS, built with Vite, content through ACF flexible content blocks.

```bash
nvm use && npm install
npm run dev     # dev server with hot reload
npm run build   # production build into build/ (commit it)
```

Documentation lives in [`docs/`](docs/README.md).
